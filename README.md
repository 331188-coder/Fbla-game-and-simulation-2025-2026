MazeMind

  MazeMind is a web-based puzzle simulation developed for the 2025-2026 FBLA Computer Game & Simulation Programming competition. The project focuses on creating an engaging user experience through logic-based navigation that simulates a certain career and smooth browser-based performance.

Project Vision

  The goal of MazeMind was to build a functional game environment using only core web technologies. I wanted to focus on clean mechanics and a layout that felt intuitive from the moment the page loads. It handles the rendering and logic directly in the browser, ensuring it stays lightweight and accessible.

Technical Details

  I built this project from scratch using a standard web stack. 
Most of the heavy lifting happens in the JavaScript files to manage the game state and player movement.

HTML5: Used for the game's core structure and UI containers.

CSS3: Handles the visual interface, positioning, and transitions.

JavaScript: Powers the game engine, collision logic, and win-state triggers.

Development Environment: Built and debugged entirely within VS Code.

How to Run Locally
If you want to look at the code or run it on your own machine:

Clone this repository.

Open the project folder in VS Code.

Launch index.html in any modern web browser.
